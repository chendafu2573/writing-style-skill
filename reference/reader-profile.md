# 读者画像填写指引

> 空白模板，当前没有预设读者群体。每次任务可以临时指定目标读者。

| 字段 | 作者填写 |
|---|---|
| 主要读者是谁 | 待填写 |
| 读者已有的背景知识 | 待填写 |
| 读者最关心的问题 | 待填写 |
| 希望读者看完知道什么 | 待填写 |
| 是否希望读者采取行动 | 待填写，可不设置 |
| 阅读场景与篇幅限制 | 待填写 |
| 需要解释的术语 | 待填写 |
| 可以直接使用的术语 | 待填写 |
| 语气与距离感 | 待填写 |
| 需要避免的误解 | 待填写 |
| 判断依据或调查范围 | 待填写，可标未知 |
| 确认日期 | 待填写 |

## 使用边界

画像是写作目标，不是关于所有读者的事实。没有调查依据时，不能把作者设想改写成“读者普遍认为”。未填写的字段保持未知；不从公开虚构样例推断真实读者。
