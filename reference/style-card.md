# 通用风格卡：待作者确认

> **这是示例通用起点，尚未个性化。** 内容是为了让流程可用的基础约束，不代表任何作者已确认的写作风格。个人偏好账本当前为空。

## 使用状态

- 个性化状态：未开始。
- 作者确认：未确认。
- 作者声音、幽默方式、句长、开头、结尾和用词偏好：均未知。
- 首次使用时先说明以上状态；结合本次任务采用必要的通用起点，不能声称“已经写得像你”。

## 示例通用起点

1. 以用户给出的目标、材料和修改范围为准。原稿中的事实、立场、引用和明确希望保留的表达先保留。
2. 每次改写都保持意思一致；涉及数字、时间、单位和主体时核对上下文，缺失信息保留未知或询问作者。
3. 区分事实、判断、愿望和第三方说法；素材没有的亲身经历、群体共识和确定性结论不自行补写。
4. 让句子便于理解；是否短句、口语、反问、排比、表情符号或专业术语，由作者和当前场景决定。
5. 遇到可能改变意思的取舍，说明差异并交由作者选择；不能只为了整齐就改变原有表达。
6. 本次完成稿与长期偏好分开处理。作者确认定稿只代表接受这篇文章，长期偏好仍需单独确认。
