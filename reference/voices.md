# voices.md（仿写口吻库）

> 只在作者说「XX 口吻」「用 XX 的语气」时读取。平时写稿不读。
> 仿写口吻是**单篇临时模式**，不是作者本人的写法，不进 DNA，不当风格证据。

## 共同规则（所有口吻都适用）

1. **作者只说一句「XX 口吻」**。用哪种具体口吻由 Agent 按素材内容和情绪自己选，不让作者挑；交稿时用一句话说明「用了哪种口吻、出自哪里」。作者点名具体口吻时照用；表里没有的口吻也可以用。
2. **优先级**：作者原稿、事实、数字、判断 > 指定口吻 > 风格卡和全部 DNA 偏好 > 通用去 AI 味规则。口吻模式下 **DNA 偏好全部暂停**（说话类和判断类都不用），不写锚点句；通用规则只拦事实错误和明显机器腔，不把口吻特征（半文半白、长句、反讽）当 AI 味改掉。
3. **原稿保护照常生效**：作者给的原话、经历、数字、立场原样保留，口吻只改「怎么说」，不改「说什么」。素材里没有的事实不补。
4. **只借口吻，不抄原文**。不编造作家原句；确需引用原文时必须准确并标出处。示范句由 Agent 自己仿写。仍在版权期内的作家（如王小波、张爱玲）不大段复述原文。
5. **存档**：存初稿时在 `draft.py save` 的 JSON 里写 `"voice": "鲁迅·梦境体"`（作家·具体口吻），不填 `anchors`；定稿时脚本自动带上，这篇照常存档，但不写复盘、风格资格为「否」。忘了标的，经作者同意后用 `python3 scripts/mark_voice.py --artifact assets/<文件名> --voice "鲁迅·梦境体"` 补标。
6. **怎么扩展**：第一次用某位作家时，Agent 凭自己的理解写；作者满意后，再按下面的格式补一节（用在什么内容 / 口吻 / 出处或特征 / 边界），不预先写一堆。
