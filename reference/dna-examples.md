# 个人偏好示例与边界

> 通用模板初始状态：没有已确认的个人偏好，本文件不提供作者风格示例。

这里用于解释个人偏好在什么条件下适用，避免把一句习惯用法机械套到所有文章。

## 填写方式

作者确认偏好后，再按对应编号填写以下内容：

| 项目 | 填写内容 |
|---|---|
| 对应偏好 | 已存在的个人偏好编号 |
| 适用场景 | 哪类材料、目标和语境适用 |
| 支持材料 | 作者授权使用的原稿或修订 |
| 应用示例 | 保留原意的写法及原因 |
| 边界示例 | 哪些情况下不应用，以及原因 |
| 作者确认 | 确认日期与范围 |

公开评测中的虚构句子只用于检验流程，不能搬进个人偏好账本作为作者证据。

## 不收录项

单篇文章里的偶然用词、素材中的第三方观点、助手自行生成的句子，以及未获授权的文字，都不能单独证明作者长期偏好。作者明确提出并确认的长期规则，按维护流程处理。
