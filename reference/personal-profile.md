# 作者画像填写指引

> 空白模板，所有字段均为待填写。当前没有作者身份、经历、立场或个人偏好。

只填写作者自愿提供并允许长期使用的信息。未填写的内容保持未知；助手不能根据题材、语气或虚构样例猜测作者经历。

| 字段 | 作者填写 |
|---|---|
| 对外称呼 | 待填写，可留空 |
| 写作身份与角色 | 待填写 |
| 常写主题 | 待填写 |
| 有真实经验的领域 | 待填写 |
| 写作目标 | 待填写 |
| 常用发布平台 | 待填写 |
| 可以公开的经历 | 待填写 |
| 需要保密的信息 | 待填写，可只说明类别 |
| 可以代表谁发言 | 待填写 |
| 希望保留的个人表达 | 待填写，需附授权例句 |
| 暂不确定的偏好 | 待填写 |
| 确认日期 | 待填写 |

## 维护方式

作者决定填什么、改什么和删什么。画像用于理解背景，不替代事实核对，也不能给助手补写亲身经历的权限。长期写法仍应经过偏好确认流程。
